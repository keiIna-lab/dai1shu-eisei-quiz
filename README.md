# 第一種衛生管理者 試験練習

ブラウザだけで動く、第一種衛生管理者の試験練習アプリです。サーバーのインストールは不要です。

## できること

- **1000問** — 五肢択一。関係法令・労働衛生・労働生理
- **一問ごとの正誤と解説** — 実試験・免除・特例でも、選んだ直後に出ます
- **実試験** — 44問・3時間・400点満点。各範囲40%以上、合計60%以上で合格
- **労働生理の免除** — 34問・2時間15分・300点満点
- **特例第一種** — 有害業務の法令と労働衛生、20問・2時間・160点満点
- **間違えた問題のやり直し**
- **項目別の成績** — 解いた問題を範囲ごとに集計

成績はブラウザの中だけに保存します。

## 使い方

このフォルダの `index.html` をブラウザで開きます。または、フォルダ内で次を実行して `http://127.0.0.1:8878/` を開きます。

```powershell
python -m http.server 8878
```

## ファイル

| ファイル | 内容 |
|---------|------|
| `index.html` | 画面 |
| `app.js` / `styles.css` | 画面と進行 |
| `logic.js` | 出題と合格判定 |
| `questions.js` | 1000問 |
| `build_questions.py` | 問題の生成 |

## 注意

問題は公開されている法令と労働生理の知識に基づく学習用です。試験協会の過去問そのものではありません。最新の法令は公式の情報で確認してください。
